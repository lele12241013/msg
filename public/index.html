Enviar popup para a tela

Deixe o servidor rodando em segundo plano. Sempre que voce enviar um texto aqui, ele aparece como popup no canto superior direito da tela do Windows.

Endpoint HTTP: POST /api/popup
Corpo JSON: { "message": "Seu texto", "durationMs": 5000 }
Inicializacao oculta: duplo clique em start-background.vbs
